# کلون نرم‌افزار حسابداری هلو (نسخه تک-فایلی)

این پروژه یک نسخه ساده شده و کاملاً مستقل از نرم‌افزار حسابداری هلو است که تنها با یک فایل HTML کار می‌کند.

## ویژگی‌ها

- **اجرای آسان:** تنها کاری که لازم است انجام دهید، باز کردن فایل `index.html` در مرورگر دلخواهتان (مثل کروم، فایرفاکس و ...) است.
- **بدون نیاز به نصب:** هیچ نیازی به نصب سرور، Node.js یا اجرای دستورات پیچیده نیست.
- **کاملاً لوکال:** تمام اطلاعات محصولات در حافظه مرورگر شما (`localStorage`) ذخیره می‌شود. این یعنی اطلاعات شما خصوصی است و به هیچ سروری ارسال نمی‌شود.
- **مدیریت کامل محصولات:** می‌توانید محصولات را اضافه، ویرایش و حذف کنید.
- **تم روشن و تاریک:** با کلیک روی دکمه ماه/خورشید در بالای صفحه، می‌توانید تم برنامه را تغییر دهید.

## نحوه استفاده

1.  فایل `index.html` را دانلود کنید.
2.  روی آن دو بار کلیک کنید تا در مرورگرتان باز شود.
3.  شروع به استفاده از برنامه کنید!

---
ساخته شده با HTML، Tailwind CSS (CDN) و جاوا اسکریپت خالص.
