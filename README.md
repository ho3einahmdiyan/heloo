# کلون نرم‌افزار حسابداری هلو (نسخه وب)

این پروژه یک نسخه ساده شده تحت وب از نرم‌افزار حسابداری هلو است که به صورت لوکال اجرا می‌شود.

## ویژگی‌های اصلی (MVP)

- مدیریت کامل محصولات (افزودن، ویرایش، حذف، مشاهده)
- رابط کاربری مدرن و مینیمال
- قابلیت تغییر تم بین حالت روشن و تاریک

## پشته تکنولوژی (Tech Stack)

- **بک‌اند:** Node.js, Express, SQLite
- **فرانت‌اند:** React, Tailwind CSS

---

## نحوه راه‌اندازی و اجرا

این پروژه از دو بخش `backend` و `frontend` تشکیل شده است که باید به صورت جداگانه اجرا شوند.

### ۱. راه‌اندازی بک‌اند (سرور)

ابتدا وارد ترمینال شده و دستورات زیر را به ترتیب در ریشه پروژه اجرا کنید:

```bash
# ورود به پوشه بک‌اند
cd backend

# نصب وابستگی‌ها
npm install

# اجرای سرور (روی http://localhost:3001)
npm start
```
سرور شما آماده است. این ترمینال را باز نگه دارید.

### ۲. راه‌اندازی فرانت‌اند (رابط کاربری)

یک ترمینال جدید باز کنید و دستورات زیر را در ریشه پروژه اجرا کنید:

```bash
# ورود به پوشه فرانت‌اند
cd frontend

# نصب وابستگی‌ها
npm install

# اجرای برنامه (یک صفحه مرورگر روی http://localhost:3000 باز می‌شود)
npm start
```

حالا می‌توانید برنامه را در مرورگر خود مشاهده و استفاده کنید.
